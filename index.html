01 - Colour palette

Three warm moods plus buttons and accents

Warm cream for daylight clarity, golden amber for evening, bright orange for all actions, and warm coral-red for accents only. The old blue has been dropped entirely. It fought against everything else and made the palette feel disjointed. With it gone, every colour now sits in the same warm family and the whole thing reads as one cohesive system. 03 - Typography

Montserrat, set with intent

The whole site is Montserrat, which is in Shopify's font library, so it loads natively in Symmetry with no workaround. The fix for the thin look the site has now is weight, not a new font.

The "light font" fix: the current site reads thin because headings sit on Montserrat's lighter and extra light weights. Do not use the extra light version. Set headings to 600-800 and body to 400 (500 for small UI text), and bump base size and line height. That alone lifts the whole site from weedy to premium.
04 - Buttons

Orange leads, everything else supports

Primary actions are always the bright orange. Pill radius, Montserrat Medium, generous padding. Define once in Symmetry's button settings.

Primary: #FF8C00 fill, dark text. Secondary: ink outline, fills ink on hover.
On dark sections, keep the bright orange. Ghost buttons use a white outline.
Accessibility note: dark text on orange provides good contrast for buttons and large text. For small body text, don't put it on orange, use #242424 instead so it stays legible.
05 - Usage rules

Keep it consistent

Do

  • Use orange for CTAs, key icons, borders and small headlines, consistently.
  • Set type globally so every page inherits the same weights.
  • Alternate light, grey and dark schemes down a page for rhythm.
  • Keep main text in #242424 and secondary text in #434447.

Avoid

  • Leaning on red. It's an occasional accent, not a section default.
  • Headings on light Montserrat weights (the current thin look).
  • Small body text sitting on the orange.
  • Stacking equal white boxes, which is what reads as "boxy" now.
06 - Imagery

Three moods, one warm language

From the brand doc's photography guide. Across all three: warm directional natural light from the top right, the lens is the brightest element and appears to radiate, visible tactile texture (wood grain, woven fabric, soft bedding), shot at 85mm f/2.0 with a Kodak Portra 400 film tone. Always avoid cold blue lighting, white fluorescent or clinical light, and bright all-white "Bali-style" bedrooms.
